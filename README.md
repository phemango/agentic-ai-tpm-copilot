# Agentic AI TPM Copilot

## Overview

This portfolio project demonstrates how I leveraged Agentic AI to support Technical Program Management (TPM) workflows across the AI project lifecycle.

The copilot supports:

**Initiate → Plan → Execute → Monitor & Control → Evaluate/Release → Close**

The project uses my **AI Knowledge Assistant** project as the example AI project being managed.

The focus is not on building a production-grade autonomous agent. The focus is on demonstrating how an experienced TPM can leverage Agentic AI for structured project execution, governance, risk management, evaluation, readiness assessment, and human-in-the-loop decision support.

---

## Why This Project

AI projects require coordination across:

- Requirements
- Stakeholders
- Planning
- Dependencies
- Risks and issues
- AI evaluation
- Security and privacy
- Operational readiness
- Release decisions
- Project closure

Agentic AI can help a TPM organize and accelerate these activities while keeping important decisions under human control.
